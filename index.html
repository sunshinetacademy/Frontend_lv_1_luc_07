الجزء الأول: Typography — الخطوط والنصوص

📖 ما هي Typography؟

Typography هو فن وعلم تنسيق النصوص. في CSS، بنستخدم خصائص عشان نتحكم في:

• نوع الخط (Font Family)

• حجم الخط (Font Size)

• سمك الخط (Font Weight)

• مائل/عادي (Font Style)

• المسافة بين السطور (Line Height)

• المسافة بين الحروف (Letter Spacing)

• محاذاة النص (Text Align)

• زخرفة النص (Text Decoration)

• تحويل النص (Text Transform)

🔹 1. Font Family — نوع الخط

بتحدد نوع الخط المستخدم. ممكن تحدد أكتر من خط كـ "fallback" لو الأول مش متاح.

CSS — Font Family 
/* خط واحد */
body {
    font-family: Arial;
}

/* قائمة خطوط (fallback) */
body {
    font-family: 'Cairo', Arial, sans-serif;
}

/* أنواع الخطوط العامة */
.serif { font-family: serif; }        /* Times, Georgia */
.sans { font-family: sans-serif; }  /* Arial, Helvetica */
.mono { font-family: monospace; }    /* Courier, Consolas */
font-family: serif
مرحباً بيك في عالم الخطوط — Hello World
font-family: sans-serif
مرحباً بيك في عالم الخطوط — Hello World
font-family: monospace
مرحباً بيك في عالم الخطوط — Hello World

⚠️ قاعدة مهمة

دايماً حط generic family في آخر القائمة (serif, sans-serif, monospace). لو كل الخطوط المحددة مش موجودة، المتصفح هيستخدم الخط الافتراضي من النوع ده.

🔹 2. Font Size — حجم الخط

بيتحكم في حجم النص. استخدمنا في المحاضرة اللي فاتت وحدات زي px و rem.

CSS — Font Size 
h1 {
    font-size: 2.5rem;  /* 40px */
}

h2 {
    font-size: 2rem;     /* 32px */
}

p {
    font-size: 1rem;      /* 16px — الافتراضي */
}

.small {
    font-size: 0.875rem; /* 14px */
}

✅ أفضل الممارسات

• استخدم rem لحجم الخط عشان يبقى متجاوب.

• الحجم الافتراضي في المتصفح = 16px = 1rem.

• متستخدمش حجم أقل من 0.875rem (14px) للنص العادي.

🔹 3. Font Weight — سمك الخط

بيتحكم في سمك/خفة الخط. من 100 (خفيف جداً) لـ 900 (عريض جداً).

CSS — Font Weight 
.light { font-weight: 300; }      /* خفيف */
.normal { font-weight: 400; }     /* عادي (default) */
.medium { font-weight: 500; }     /* متوسط */
.bold { font-weight: 700; }       /* عريض (bold) */
.black { font-weight: 900; }      /* عريض جداً */

/* كلمات مفتاحية */
.normal2 { font-weight: normal; }  /* = 400 */
.bold2 { font-weight: bold; }      /* = 700 */
font-weight: 300 (light)
مرحباً بيك — Hello World
font-weight: 400 (normal)
مرحباً بيك — Hello World
font-weight: 700 (bold)
مرحباً بيك — Hello World
font-weight: 900 (black)
مرحباً بيك — Hello World

🔹 4. Font Style — مائل/عادي

بيتحكم في ميلان النص.

CSS — Font Style 
.normal { font-style: normal; }   /* عادي */
.italic { font-style: italic; }   /* مائل */
.oblique { font-style: oblique; } /* مائل بقوة */
font-style: normal
مرحباً بيك في عالم الخطوط
font-style: italic
مرحباً بيك في عالم الخطوط

🔹 5. Line Height — المسافة بين السطور

بيتحكم في المسافة العمودية بين السطور. مهم جداً لسهولة القراءة.

CSS — Line Height 
.tight {
    line-height: 1;      /* مضغوط */
}

.normal {
    line-height: 1.5;    /* عادي — الأفضل */
}

.loose {
    line-height: 2;      /* واسع */
}

/* ممكن نستخدم px كمان */
.fixed {
    line-height: 24px;

• للعناوين: 1.1 إلى 1.3.

🔹 10. Google Fonts — خطوط ويب احترافية

Google Fonts مكتبة مجانية فيها آلاف الخطوط. بنستخدمها عشان نضيف خطوط حلوة لموقعنا.

HTML — إضافة Google Fonts 
<head>
    <!-- ربط الخط من Google Fonts -->
    <link rel="preconnect" href="https://fonts.googleapis.com">
    <link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
    <link href="https://fonts.googleapis.com/css2?family=Cairo:wght@400;700;900&display=swap" rel="stylesheet">
</head>
CSS — استخدام الخط 
body {
    font-family: 'Cairo', sans-serif;
}

h1 {
    font-family: 'Cairo', sans-serif;
    font-weight: 900;
}

💡 نصيحة

استخدم display=swap في الرابط عشان النص يظهر بسرعة حتى لو الخط لسه بيتحمل. وكمان اختار خط يدعم اللغة العربية لو هتستخدمها.

الجزء الثاني: Box Model — نموذج الصندوق

📖 ما هو Box Model؟

Box Model هو أهم مفهوم في CSS. كل عنصر في الصفحة هو "صندوق" (Box)، وكل صندوق بيتكون من 4 طبقات:

💡 تشبيه من الحياة

تخيل إنك بتبعت هدية بالبريد:

  • Content = الهدية نفسها (المحتوى)
  • Padding = الفقاقيس البلاستيك حوالين الهدية (مسافة داخلية)
  • Border = كرتون العلبة (الحدود)
  • Margin = المسافة بين العلبة والعلب التانية (مسافة خارجية)

📦 نموذج الصندوق (Box Model)

Content

Margin: المسافة الخارجية (شفاف عادةً)

Border: الحدود حول العنصر

Padding: المسافة الداخلية

Content: المحتوى نفسه

🔹 1. Content — المحتوى

المحتوى نفسه: النص، الصورة، الفيديو، أي حاجة جوه العنصر.

مقاس المحتوى بيتحدد بـ width و height.

CSS — Content Size 
.box {
    width: 300px;
    height: 200px;
}

🔹 2. Padding — المسافة الداخلية

المسافة بين المحتوى و الحدود (border). المسافة دي جوه العنصر وبتأثر على حجمه.

CSS — Padding 
/* نفس المسافة من كل الجهات */
.box1 {
    padding: 20px;
}

/* علوي/سفلي | يمين/يسار */
.box2 {
    padding: 20px 40px;
}

/* علوي | يمين | سفلي | يسار (clockwise) */
.box3 {
    padding: 10px 20px 30px 40px;
}

/* كل جهة لوحدها */
.box4 {
    padding-top: 10px;
    padding-right: 20px;
    padding-bottom: 30px;
    padding-left: 40px;
}

🔹 3. Border — الحدود

الحدود حول العنصر. ليها 3 خصائص: width, style, color.

CSS — Border 
/* Shorthand — كلهم في سطر */
.box {
    border: 2px solid #4A7C59;
}

/* كل property لوحدها */
.box2 {
    border-width: 3px;
    border-style: dashed;
    border-color: #D4A574;
}

/* border-radius — زوايا دائرية */
.rounded {
    border-radius: 10px;
}

.circle {
    border-radius: 50%; /* دائرة كاملة */
}

🔍 Border Styles

Style الشكل الاستخدام
solid خط مستمر الأكثر استخداماً
dashed خط متقطع حدود مؤقتة
dotted نقط تصاميم خاصة
double خط مزدوج تصاميم خاصة
none بدون حدود إزالة الحدود

🔹 4. Margin — المسافة الخارجية

المسافة خارج العنصر، بينه وبين العناصر التانية. مش بتأثر على حجم العنصر نفسه.

CSS — Margin 
/* نفس المسافة من كل الجهات */
.box1 {
    margin: 20px;
}

/* علوي/سفلي | يمين/يسار */
.box2 {
    margin: 20px 40px;
}

/* علوي | يمين | سفلي | يسار */
.box3 {
    margin: 10px 20px 30px 40px;
}

/* توسيط العنصر أفقياً */
.centered {
    margin: 0 auto;
    width: 80%;
}

💡 margin: 0 auto

دي طريقة شهيرة لتوسيط عنصر أفقياً. لازم يكون للعنصر width محدد. الـ auto بيخلي المتصفح يقسم المسافة المتبقية بالتساوي على اليمين والشمال.

🔹 Margin Collapse — انهيار الهوامش

لما يكون عندك عنصرين فوق بعض، واللي فوق عنده margin-bottom: 30px واللي تحت عنده margin-top: 20px، المسافة بينهم مش هتكون 50px — هتكون 30px (الأكبر).

⚠️ قاعدة Margin Collapse

• بيحصل بس في الـ vertical margins (فوق/تحت).

• مش بيحصل في الـ horizontal margins (يمين/شمال).

• مش بيحصل لو العنصرين عندهم padding أو border بينهم.

• مش بيحصل في Flexbox و Grid (هنشوفهم بعدين).

🔹 Box Sizing — طريقة حساب الحجم

في طريقتين لحساب الحجم الكلي للعنصر:

content-box
الافتراضي

width = المحتوى بس.
Padding + Border بيتضافوا فوق.

⚠️ الحجم الكلي = width + padding + border

border-box
الأفضل ⭐

width = المحتوى + padding + border.
أسهل في الحساب والتحكم.

✓ الحجم الكلي = width فقط

CSS — Box Sizing 
/* الطريقة الافتراضية */
.content-box {
    box-sizing: content-box;
    width: 300px;
    padding: 20px;
    border: 2px solid ;
    /* الحجم الكلي = 300 + 40 + 4 = 344px */
}

/* الطريقة الأفضل */
.border-box {
    box-sizing: border-box;
    width: 300px;
    padding: 20px;
    border: 2px solid ;
    /* الحجم الكلي = 300px (ثابت) */
}

/* Global Reset — Best Practice */
* {
    box-sizing: border-box;
}

✅ ليه border-box أفضل؟

1. سهل الحساب: width = الحجم الكلي دايماً.

2. متوقع: لو حددت width: 300px، العنصر هيكون 300px فعلاً.

3. أسهل في Layout: مش هتفاجأ إن العنصر كبر لما ضفت padding أو border.

🚨 لازم تعمل Reset

دايماً حط الكود ده في أول ملف CSS:

* { margin: 0; padding: 0; box-sizing: border-box; }

🧮 حساب الحجم الكلي

مثال عملي على حساب الحجم الكلي لعنصر:

مثال حساب 
.card {
    width: 300px;
    padding: 20px;
    border: 2px solid ;
    margin: 30px;
}

/* content-box (الافتراضي): */
/* الحجم الكلي = 300 + (20×2) + (2×2) = 344px */
/* المساحة المأخوذة = 344 + (30×2) = 404px */

/* border-box: */
/* الحجم الكلي = 300px (ثابت) */
/* المساحة المأخوذة = 300 + (30×2) = 360px */

📊 مقارنة مرئية

Box Sizing Width Padding Border الحجم الكلي
content-box 300px 20px × 2 2px × 2 344px
border-box 300px 20px × 2 2px × 2 300px ✓

Debugging — اكتشف الأخطاء

🔍 نشاط: اكتشف الأخطاء في CSS ده

الكود ده فيه 5 أخطاء شائعة في Typography و Box Model.

CSS — كود فيه أخطاء ❌ 
body {
    font-family: Cairo;
}

.card {
    width: 300;
    padding: 20;
    margin: 10 20 30;
    border: 2px #4A7C59;
}
❌ الأخطاء
1. font-family ناقص quotes و fallback
2. width ناقص وحدة (px)
3. padding ناقص وحدة
4. margin 3 values (لازم 1, 2, أو 4)
5. border ناقص style (solid)
✅ الكود الصحيح
body {
  font-family: 'Cairo', sans-serif;
}

.card {
  width: 300px;
  padding: 20px;
  margin: 10px 20px 30px 20px;
  border: 2px solid #4A7C59;
}

  • font-weight: سمك الخط (100-900, normal, bold)
  • font-style: italic, normal, oblique
  • line-height: المسافة بين السطور (1.5-1.8 للنصوص)
  • letter-spacing: المسافة بين الحروف
  • text-align: left, center, right, justify
  • text-decoration: underline, line-through, none
  • text-transform: uppercase, lowercase, capitalize
  • Google Fonts: خطوط ويب مجانية واحترافية
  • Box Model: Content + Padding + Border + Margin
  • Padding = المسافة الداخلية، Margin = المسافة الخارجية
  • box-sizing: border-box أفضل من content-box
  • Global Reset: * { margin: 0; padding: 0; box-sizing: border-box; }
  • margin: 0 auto لتوسيط عنصر أفقياً
  • Margin Collapse: المسافة بين عنصرين عمودياً = الأكبر مش المجموع

أسئلة اختيار من متعدد

10 أسئلة لاختبار فهمك لمحتوى المحاضرة

سؤال 1

ما هو property اللي بيحدد نوع الخط؟

  • أ font-style
  • ب font-family
  • ج font-weight
  • د text-font
سؤال 2

ما هي القيمة المثالية لـ line-height للنصوص الطويلة؟

  • أ 0.5
  • ب 1.0
  • ج 1.5 - 1.8
  • د 3.0
سؤال 3

ما هو الفرق بين padding و margin؟

  • أ مفيش فرق
  • ب padding = خارجي، margin = داخلي
  • ج padding = داخلي، margin = خارجي
  • د padding للخطوط، margin للألوان
سؤال 4

ما هي قيمة box-sizing الأفضل؟

  • أ content-box
  • ب border-box
  • ج padding-box
  • د margin-box
سؤال 5

ما هو property اللي بيحول النص لـ UPPERCASE؟

  • أ text-style: upper
  • ب font-transform: uppercase
  • ج text-transform: uppercase
  • د text-case: upper
سؤال 6

كيف توسط عنصر أفقياً بـ margin؟

  • أ margin: center
  • ب margin: 0 auto
  • ج margin: auto 0
  • د margin: middle
سؤال 7

ما هو Margin Collapse؟

  • أ المسافة بين عنصرين = مجموع الـ margins
  • ب المسافة بين عنصرين عمودياً = الـ margin الأكبر
  • ج إزالة كل الـ margins تلقائياً
  • د إضافة margins تلقائياً
سؤال 8

ما هو border-radius: 50% بيعمل؟

  • أ زوايا حادة
  • ب زوايا دائرية خفيفة
  • ج شكل دائري كامل
  • د إزالة الحدود
سؤال 9

ما هي أفضل وحدة لـ font-size؟

  • أ px
  • ب em
  • ج rem
  • د %
سؤال 10

ما هو Global Reset الصحيح؟

  • أ * { margin: 0; padding: 0; }
  • ب * { margin: 0; padding: 0; box-sizing: border-box; }
  • ج body { margin: 0; padding: 0; }
  • د * { box-sizing: content-box; }
